# Agent Harness

This directory collects the agent-facing parts of the repository in one place.

## Layout

- `frontend/`
  - Local browser control room and memory integration.
- `pi-agent/`
  - Pi-based gameplay runner, prompts, and pinned runtime.
- `skills/`
  - Local STS2 gameplay skills shared by the runners.

## Notes

- `agent-harness/...` is the canonical location for harness code and docs.
